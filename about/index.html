01 · 片库

创新道德教育是什么

创新道德教育是一个中文讲座视频库，内容涉及品德、家庭生活与诚信做事，为家长和老师而做。

中文站收录全部视频；英文版是精选，加有英文字幕和简短注释，好让文化背景不丢。

02 · 编辑流程

我们如何选片与翻译

  1. 01

    选题

    我们挑选适合家庭和课堂的讲座。

  2. 02

    翻译

    英文字幕逐句撰写、逐行校对。

  3. 03

    审核

    另一位审核人检查译文，以及对谚语和观念所做的简短注释。

    只讲背景，不发议论

  4. 04

    发布

    审核完成后，讲座才会上线。

04 · 您的数据

隐私与联系

看视频，不被盯着

目前本站没有做任何访问统计，也不跟踪个人。

网站托管在 GitHub Pages。托管方 GitHub 会处理访问日志（例如 IP 地址与浏览器信息），这些日志在 GitHub 手里，我们自己看不到。

  • 点击播放前不连接 YouTube
  • 没有广告跟踪
  • 观看进度只存在本机
  • 无需账号

统计 · 暂无 · 托管 · GITHUB PAGES

视频由 YouTube 播放。打开页面时不会连接 YouTube；您点击播放之后，YouTube（Google）才会看到您的 IP 地址并按它自己的规则处理数据。字号设置和观看进度只保存在您自己浏览器的本机存储里，不会上传。
